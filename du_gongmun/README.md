# 동서울대 공문 아침 브리핑 (맥)

평일 아침마다 맥이 알아서 그룹웨어에 **새로 로그인**해서 공문 수신함, 결재 대기, 일정을 읽은 뒤
아래 형태로 정리해 **카카오톡 '나와의 채팅'**으로 보내 드립니다.

```
📋 11/18(수) 공문 브리핑
교육과정 개편안 제출 마감이 이번 주 금요일입니다.

✅ 해야 할 일 (1)
🔴 교육과정 개편안 제출 ~11/20(금)
   → 11/20까지 학과 개편안 제출

📌 공문 (2)
🆕 연구윤리 교육 이수 안내
· 2학기 강의평가 실시 안내

📅 일정 (1)
· 학과 회의 11/19(목)
```

- 🔴 마감 3일 이내 · 🆕 어제 브리핑에 없던 새 항목
- 매번 새로 로그인하므로 **로그인이 풀리는 문제가 없습니다.**
- 비밀번호는 **맥 키체인에만** 저장됩니다. 파일이나 다른 곳에 남지 않습니다.
- 전체 내용은 `~/Documents/공문브리핑/날짜.txt` 에도 저장됩니다.
- 실패하면 "⚠️ 공문 브리핑 실패" 카톡이 옵니다.

## 준비물 (처음 한 번, 약 20분)

### ① 카카오 개발자 앱 만들기 — 카톡 '나에게 보내기'용
1. https://developers.kakao.com 에 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가** (이름: 공문브리핑)
2. **앱 키**에서 **REST API 키**를 복사해 둡니다.
3. **카카오 로그인 → 활성화 ON**, **Redirect URI**에 `http://localhost:8765/callback` 등록
4. **카카오 로그인 → 동의항목 → "카카오톡 메시지 전송(talk_message)"** 을 '선택 동의'로 설정
5. **플랫폼 → Web → 사이트 도메인**에 `http://localhost:8765` 와 포털 주소(예: `https://portal.du.ac.kr`) 등록

> 카카오 화면 메뉴 이름은 조금씩 바뀝니다. 위치가 다르면 화면을 캡처해서 Claude에게 물어보세요.

### ② (권장) Claude API 키 — 공문을 읽고 '할 일'로 정리하는 기능
- https://console.anthropic.com 에서 API 키를 발급받습니다. 하루 한 번 요약하는 데 드는 비용은 몇십 원 수준입니다.
- 키가 없어도 동작하지만, 그때는 공문 목록만 그대로 보냅니다.

## 설치

터미널을 열고:

```bash
cd ~/jin                        # 이 저장소를 받아 둔 폴더
git pull
cd du_gongmun
./install_mac.sh 07:30          # 처음 실행 → config.yaml 이 열림
```

1. 열린 `config.yaml`에 **포털 로그인 주소**와 **아이디**를 넣고 저장합니다.
2. `./install_mac.sh 07:30` 을 **다시 실행**하면
   - 포털 비밀번호와 Claude API 키를 물어봅니다. 입력해도 화면에는 보이지 않습니다.
   - 카카오 로그인 창이 뜨면 **동의**를 누르고, 카톡 REST API 키를 붙여넣습니다.
   - 평일 7시 30분 자동 실행이 등록됩니다.

## 그룹웨어 메뉴 맞추기 (중요)

학교 그룹웨어의 메뉴 이름에 맞춰 `config.yaml`의 `pages:` 항목을 고쳐야 합니다.

```yaml
pages:
  - name: 공문 수신함
    click: ["그룹웨어", "전자결재", "수신함"]   # 로그인 후 차례로 누르는 메뉴 글자
  - name: 일정
    url: "https://gw.du.ac.kr/schedule/..."    # 또는 그 화면 주소를 바로 넣어도 됨
```

화면을 띄워서 시험해 보세요:

```bash
.venv/bin/python brief.py --dry-run --show --debug
```

- `--show`: 브라우저 창이 떠서 진행 과정이 보입니다.
- `--dry-run`: 카톡은 보내지 않고 결과만 터미널에 출력합니다.
- `--debug`: 각 단계의 화면이 `debug/` 폴더에 캡처됩니다. 메뉴를 못 찾으면 이 캡처를 Claude에게 보여주세요.
  캡처에 개인정보가 보일 수 있으니 보낼 때는 가려주세요.

잘 나오면 `--dry-run` 없이 한 번 실행해서 카톡이 오는지 확인하면 끝입니다.

## 자주 묻는 것

| 상황 | 방법 |
|---|---|
| 맥이 잠자기 상태였다 | 깨어나면 바로 실행됩니다. 맥이 **꺼져** 있었으면 그날은 건너뜁니다. |
| 맥을 아침에 자동으로 켜고 싶다 | `sudo pmset repeat wakeorpoweron MTWRF 07:25:00` |
| 시간 바꾸기 | `./install_mac.sh 08:00` |
| 비밀번호를 바꿨다 | `.venv/bin/python setup_secrets.py` |
| 카톡 테스트 | `.venv/bin/python kakao.py test` |
| 기록 보기 | `logs/brief.log` |
| 자동 실행 끄기 | `launchctl bootout gui/$(id -u)/kr.ac.du.gongmun-brief` |
| 사이트가 자동 브라우저를 막는다 | `config.yaml`에 `browser_channel: "chrome"` 추가 (설치된 크롬 사용) |

> 학교 규정상 자동 접속이 제한되는지 한 번 확인해 두시면 좋습니다. 이 프로그램은 하루 한 번, 본인 계정으로, 화면을 읽기만 합니다.
