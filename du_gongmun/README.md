# 동서울대 공문 아침 브리핑 (맥, 무료)

평일 아침마다 맥이 알아서 포털에 **새로 로그인**해서 **공람대기 목록에서 지난 브리핑 이후 새로 들어온 공문만** 골라 본문까지 읽고,
**우리 학과(config의 `department`)와 관련 없는 공문은 빼고** 해야 할 일 위주로 정리해 **카카오톡 나와의 채팅**으로 보내 드립니다.

```
📋 11/19(목) 공문 브리핑
📊 결재대기 1건 · 수/발신대기 0/0건 · 공람대기 10908건
11/18(수) 이후 새 공람 23건 확인

📝 제출·회신해야 할 것 (1)
🔴 2027 교육과정 개편 학과별 의견 제출 요청 ~11/25(수) [교무처]
   각 학과는 교육과정 의견을 제출
   → 11/25까지 처리

🎵 학과 관련 공문 (1)
🆕 창작지원 공모 안내 [산학협력단]

(학과와 관련 없는 21건은 뺐습니다)
```

- 월요일에는 금요일 브리핑 이후(주말 포함) 들어온 공문을 모아서 보여줍니다. 한 번 보낸 공문은 다시 나오지 않습니다.
- 매번 새로 로그인하므로 로그인이 풀리는 문제가 없습니다. 비밀번호는 **맥 키체인에만** 저장됩니다.
- 전체 내용은 `~/Documents/공문브리핑/날짜.txt` 에도 저장됩니다.

| 기능 | 방식 | 비용 |

> 유료 Claude API는 원할 때만 켤 수 있습니다(`summarizer: api`). 기본값은 꺼져 있습니다.

## 설치

터미널을 열고:

```bash
cd ~/jin && git fetch && git checkout ccr-7b7da8c1-qj6kl9
cd du_gongmun
./install_mac.sh 07:30          # 처음 실행 → config.yaml 이 열림
```

1. 열린 `config.yaml`에 아래 내용을 넣고 저장합니다.
   - `login_url`: 포털 로그인 주소
   - `username`: 아이디
   - `email_to`: 브리핑 받을 내 지메일 주소
2. **지메일 앱 비밀번호 만들기** (메일을 프로그램이 보내려면 필요, 무료)
   1. https://myaccount.google.com/security 에서 **2단계 인증**을 켭니다. 이미 켜져 있으면 건너뜁니다.
   2. https://myaccount.google.com/apppasswords 에서 앱 이름에 "공문브리핑"을 넣고 **만들기**를 누릅니다.
   3. 화면에 나온 16자리를 복사해 둡니다. 평소 쓰는 구글 비밀번호가 아닙니다.
3. `./install_mac.sh 07:30` 을 **다시 실행**합니다. 포털 비밀번호와 지메일 앱 비밀번호를 물어보면 입력하세요. 입력해도 화면에는 보이지 않습니다.
4. 평일 7시 30분 자동 실행이 등록됩니다. 갤럭시의 Gmail 앱 알림이 켜져 있으면 폰으로 바로 옵니다.

### 받는 곳 고르기 (`config.yaml`의 `delivery`)
- `mac`: 맥 화면에 알림이 뜨고 브리핑 파일이 자동으로 열립니다.
- `email`: 지메일로 옵니다. 갤럭시에서는 Gmail 앱 알림으로 받습니다. (기본값)
- `kakao`: 카카오톡 나와의 채팅으로 옵니다. 무료지만 카카오 개발자 앱을 만들어야 합니다(`kakao.py` 참고).
- `imessage`: 아이폰 사용자용입니다.

## 그룹웨어 메뉴 맞추기 (중요)

학교 그룹웨어의 메뉴 이름에 맞춰 `config.yaml`의 `pages:` 항목을 고쳐야 합니다.

```yaml
pages:
  - name: 공문 수신함
    click: ["그룹웨어", "전자결재", "수신함"]   # 로그인 후 차례로 누르는 메뉴 글자
  - name: 일정
    url: "https://..."                          # 또는 그 화면 주소를 바로 넣어도 됨
```

화면을 띄워서 시험해 보세요:

```bash
.venv/bin/python brief.py --dry-run --show --debug
```

- `--show`: 브라우저 창이 떠서 진행 과정이 보입니다.
- `--dry-run`: 보내지 않고 결과만 터미널에 출력합니다.
- `--debug`: 각 단계의 화면이 `debug/` 폴더에 캡처됩니다. 메뉴를 못 찾으면 이 캡처를 Claude에게 보여주세요.
  캡처에 개인정보가 보일 수 있으니 보낼 때는 가려주세요.

잘 나오면 `--dry-run` 없이 한 번 실행해서 알림이나 메시지가 오는지 확인하면 끝입니다.

## 자주 묻는 것

| 상황 | 방법 |
|---|---|
| 맥이 잠자기 상태였다 | 깨어나면 바로 실행됩니다. 맥이 **꺼져** 있었으면 그날은 건너뜁니다. |
| 맥을 아침에 자동으로 켜고 싶다 | `sudo pmset repeat wakeorpoweron MTWRF 07:25:00` |
| 시간 바꾸기 | `./install_mac.sh 08:00` |
| 비밀번호를 바꿨다 | `.venv/bin/python setup_secrets.py` |
| Claude Code를 못 찾는다고 나온다 | 터미널에서 `which claude` 로 위치를 확인해 `config.yaml`에 `claude_path:`로 넣기 |
| 기록 보기 | `logs/brief.log` |
| 자동 실행 끄기 | `launchctl bootout gui/$(id -u)/kr.ac.du.gongmun-brief` |
| 사이트가 자동 브라우저를 막는다 | `config.yaml`에 `browser_channel: "chrome"` 추가 (설치된 크롬 사용) |
| 카카오톡도 받고 싶다 | `kakao.py` 안내대로 카카오 개발자 앱(무료)을 만들고 `delivery`에 `kakao` 추가 |

> 학교 규정상 자동 접속이 제한되는지 한 번 확인해 두시면 좋습니다. 이 프로그램은 하루 한 번, 본인 계정으로, 화면을 읽기만 합니다.
